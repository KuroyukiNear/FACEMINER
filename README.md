# FACEMINER
Scrape images from thispersondoesnotexist.com and allow the user to manually label the faces.

**Saves to:**

YAML property in a markdown file. (For Obsidian.md)

JSON values in `dataset.json`.

#

### FACEMINER Versions
`main.py` is the default version that downloads the image and lets you label it.
`crop.py` does the same thing as `main.py` but it crops the watermark at the bottom of the image out before saving it.
